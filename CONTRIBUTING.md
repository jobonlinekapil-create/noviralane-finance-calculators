# Contributing

Thanks for helping make these calculators clearer and more reliable.

1. Open an issue before changing a formula or adding jurisdiction-specific rules. Explain the intended audience and cite an official source for any rule.
2. Keep personal or client financial data out of issues, tests and screenshots.
3. Add tests for arithmetic and edge cases. Run `node --test` before opening a pull request.
4. Check keyboard use, labels, error messages and small screens for interface changes.
5. Describe what changed, why it matters and any assumptions or limitations.

Maintainers review contributions when available. No response-time guarantee is implied.
